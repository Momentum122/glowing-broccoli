GalacticaOS
GalacticOS is a very lightweight OS and by lightweight i mean very lightweight less than 50kb for the code (excluding images) , futuristic , web-based OS UI built with HTML , CSS, and Vanilla JavaScript and also with the help of Hackclub's Jam (https://jams.hackclub.com/batch/webOS) .It feautures a transclucent , Space themed glassmorphism asthetic , draggable windows , desktop Shortcuts, an interactive Notes App , an interactive Clock with which you can see time , day , date and year, and alarm timer which is in seconds.

Features 
I have tried to add many features for this project . Many more will come in WebOS2.
The features are listed below :-
1.  Draggable Windows : Smoothly move Active app. windows across the Desktop by clicking and holding their header bars.
2.  Closable Windows : Close and open Applications easily with just a click of a button.
3.  Modern UI :- The Applications have very modern looking UI using Modern Backdrop blurring , glowing accents and high tech UI styling 
4.  Notes:- A very lightweight desktop app for taking quick notes.
5.  Clock and Alarm Application :- 
   - Displays real-time local time (IST UTC/GMT +5:30 hours) and full date with day and year.
   - Interactive timer that starts a countdown Alert.
6.  Top Bar :- Can Open main window , Shows current time ,date , day and year and shows current status.
7.  Desktop icons :- 
   - Tap once to select the icon of the Application
   - Double tap to open the Application
